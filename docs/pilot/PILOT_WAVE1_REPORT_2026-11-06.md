## สิ่งที่พบและแก้แล้ว

| สคริปต์ Pilot เขียนรหัสผ่านลง report และอาจรั่วผ่านข้อความ error ของ ffprobe | รหัสผ่านอยู่ในไฟล์ report | Report ไม่เก็บ login, ไม่ยอมเขียนไฟล์ถ้าพบ และรับ login ผ่าน pipe จากระบบ |

## ข้อจำกัดที่ยังอยู่

1. **MD ส่ง keyframe ห่างประมาณ 19 วินาที** (NVR EOE ~2 วินาที, DVR ~1 วินาที) วัดจาก Ch1 และ Ch2 ทำให้:
   - ย้อนหลังอาจจอดำได้ถึง ~20 วินาทีก่อนภาพขึ้น เมื่อ WebRTC พลาด keyframe แรก
   - ภาพเริ่มจาก keyframe ก่อนเวลาที่ขอ เวลาบนหน้าเว็บจึงอาจนำภาพอยู่ถึงหนึ่งช่วง keyframe (พบ 6 และ 12 วินาที) จึงเปลี่ยนข้อความในหน้าให้ยึดเวลาบนภาพเป็นหลัก
   - **คลิปจาก MD อาจขาดช่วงท้ายได้** เพราะอาจเริ่มก่อนเวลาที่ขอแต่ความยาวเท่าเดิม ข้อนี้อนุมานจากพฤติกรรมข้างต้น ยังไม่ได้ทดสอบโดยตรง
   - วิธีแก้ที่ตรงจุด: ตั้ง I-Frame Interval ที่ MD เป็น 1–2 เท่าของ FPS ตาม runbook แล้วทดสอบซ้ำ
2. **นาฬิกาเครื่องไม่ตรง:** DVR เร็ว 3 นาที 22 วินาที, NVR EOE เร็ว 7 นาที 41 วินาที, MD ช้า 8 นาที 2 วินาที (ระบบเทียบให้แล้ว แต่ควรตั้ง NTP)
3. **เสียงยังไม่ได้ทดสอบ:** DVR และ MD ใช้ G.711
4. **เฟรมตก 3–4% บน NVR EOE** วัดจาก headless Chrome เครื่องเดียว ยังไม่รู้สาเหตุ และภาพไม่ค้าง
5. **DVR Ch4 แสดงข้อความ `VERSION / VIDEO OUT`** ค้างบนภาพ คล้ายเมนูของตัวกล้อง ควรตรวจหน้างาน
6. **`/health` ตอบช้า 3.4–5 วินาที** เพราะรอ SeaweedFS ที่ไม่ได้เปิดบนเครื่อง Dev (timeout 5 วินาที) API อื่นตอบ 5–17ms แต่วัดหลังจบการทดสอบ ไม่ได้วัดระหว่างเปิดภาพ 10 ตัว
7. **แจ้งเตือนซ้ำ:** `Emergency FIFO Eviction Triggered` ขึ้นทุกรอบตรวจ สะสม 81 รายการ เพราะดิสก์ค้างที่ 93%

## ขอบเขตที่ยังไม่ได้พิสูจน์

- การทำงานต่อเนื่องเกิน 30 นาที เช่น ข้ามคืน หรือช่วงเปลี่ยนแสง
- ผู้ชมหลายคนพร้อมกัน และเบราว์เซอร์หรือเครื่องอื่น (ทดสอบบน Chrome เครื่อง Dev เครื่องเดียว)

- PTZ และ ONVIF Discovery

## ขั้นตอนรันซ้ำ

Login อ่านจากฐานข้อมูลผ่าน pipe จึงไม่มีรหัสผ่านอยู่ในไฟล์

```bash
docker cp scripts/pilot-cameras-from-platform.mjs cctv-api:/tmp/
docker cp scripts/pilot-verify-cameras.mjs cctv-api:/tmp/
docker exec cctv-api sh -c 'cd /tmp && node pilot-cameras-from-platform.mjs <cameraId>... \
  | node pilot-verify-cameras.mjs --config - --output /tmp/pilot-report.json'
docker cp cctv-api:/tmp/pilot-report.json docs/pilot/pilot-wave1-preflight-<วันที่>.json
```
